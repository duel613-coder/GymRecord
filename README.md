# ジムログ

日々のジムのトレーニングを記録する PWA。**データは端末の中に保存されます。**外部への送信は、任意で有効にできる Dropbox バックアップ（第5章）だけです。

## ファイル構成

```
index.html               アプリ本体（HTML / CSS / JS すべて内包）
sw.js                    Service Worker（オフライン動作用）
manifest.webmanifest     PWA の定義
apple-touch-icon.png     iOS ホーム画面アイコン（180px）
icon-192.png             PWA アイコン
icon-512.png             PWA アイコン
icon-maskable-512.png    Android 等のマスク対応アイコン
favicon-32.png           ブラウザのタブアイコン
```

外部 CDN・Web フォント・解析スクリプトへの参照は一切ありません。初回アクセス後は完全にオフラインで動作します。

---

## 1. GitHub Pages に設置する

1. GitHub で新しいリポジトリを作る（例：`gymlog`）
   - 無料アカウントの場合、GitHub Pages を使うには **Public リポジトリ**にする必要があります
   - トレーニング記録はリポジトリに入らない（端末内にのみ保存される）ので、Public でも記録は公開されません
2. 上記ファイルをリポジトリの**ルート**にそのまま置いて push
3. リポジトリの **Settings → Pages** を開く
4. **Source** で `Deploy from a branch`、Branch は `main` / `/ (root)` を選んで Save
5. 1〜2 分待つと `https://<ユーザー名>.github.io/gymlog/` で公開される

> GitHub を使わない場合、Netlify Drop（https://app.netlify.com/drop）や Cloudflare Pages にフォルダをドラッグするだけでも同じことができます。いずれも https で配信されるため PWA として動作します。

---

## 2. iPhone のホーム画面に追加する

1. **Safari** で `https://<ユーザー名>.github.io/gymlog/` を開く（Chrome や他のアプリ内ブラウザでは不可）
2. 下部の共有ボタン（□に↑）をタップ
3. **「ホーム画面に追加」** を選ぶ
4. ホーム画面のアイコンから起動すると、アドレスバーのない全画面のアプリとして開く

一度この状態で開いておけば、以降は**圏外・機内モードでも起動します**（Service Worker がアプリ本体をキャッシュするため）。

---

## 3. アプリを更新する

1. `index.html` などを編集する
2. **`sw.js` の 1 行目付近にある `CACHE` の番号を必ず上げる**
   ```js
   const CACHE = "gymlog-v4";   →   const CACHE = "gymlog-v5";
   ```
   これを忘れると、端末に古いキャッシュが残って新しい版が反映されません
3. push する
4. iPhone でアプリを開くと「新しいバージョンがあります」と表示されるので「更新」をタップ

## 4. データについて

- 保存先は端末内の **localStorage と IndexedDB の両方**。片方が消えてももう片方から復旧します
- 外部への送信は、Dropbox バックアップ（第5章）を有効にしたときだけ行われます
- ただし次の場合は消えます：
  - Safari の「履歴とWebサイトデータを消去」
  - ホーム画面からアプリを削除
  - iOS のストレージ逼迫時の自動削除
- **設定画面から定期的に JSON バックアップを書き出してください。** 最後のバックアップから 30 日経つと設定画面に警告が出ます
- 書き出した JSON は「バックアップから復元」で読み込めます。同じ日付は新しい方が残る形で統合されます
- CSV 書き出しは Excel / Numbers 用（日付・種目・セット・重量・回数・ボリューム・推定1RM・メモ）

## 5. Dropbox に自動バックアップする（任意）

設定画面の「Dropbox 自動バックアップ」から接続すると、**最後の操作から15秒間なにもしなかったとき**とアプリを開いたときに、Dropbox のアプリ専用フォルダへ自動で保存されます。トレーニング中に連続で入力していても送信は1回にまとまります。

### 準備（初回のみ）

1. [Dropbox App Console](https://www.dropbox.com/developers/apps) で **Create app**
2. **Scoped access** →「**App folder**」→ アプリ名を入力（例：ジムログ）
3. **Permissions** タブで `files.content.write` と `files.content.read` にチェックして **Submit**
4. **Settings** タブの **App key** をコピーし、アプリの設定画面に貼り付けて「保存」
5. 「認証ページを開く」→ Dropbox で「許可」→ 表示された**認証コードをコピー**
6. アプリに戻ってコードを貼り付け、「接続」

「App folder」を選ぶことで、このアプリが触れるのは `アプリ/<アプリ名>/` の中だけになります。Dropbox 内の他のファイルには一切アクセスできません。

### 保存されるもの

| パス | 内容 |
|---|---|
| `/gymlog-backup.json` | 最新の全データ（毎回上書き） |
| `/history/gymlog-YYYY-MM-DD.json` | 日付ごとのスナップショット（1日1回） |

どちらも設定画面の「バックアップから復元」でそのまま読み込めます。

### 注意点

- **App key と認証トークンは端末内にのみ保存**され、リポジトリには含まれません
- iOS はバックグラウンド実行ができないため、**アプリを開いている間にしか送信されません**。入力の手が止まって15秒で送られるので実用上は問題ありませんが、閉じている間の自動送信はできません
- 圏外のときは送信を保留し、次にオンラインでアプリを開いたときに送ります。ヘッダーに「Dropbox 未同期」と出ている間は未送信です
- Google ドライブは、ブラウザだけで動くアプリにリフレッシュトークンを発行しないため（1時間ごとに再ログインが必要になる）対応していません

## 6. Windows で動作確認する

`file://` で直接開くと Service Worker と一部の保存機能が動きません。簡易サーバー経由で確認してください。

```powershell
# このフォルダで
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます（localhost は例外的に Service Worker が動きます）。

同じ Wi-Fi の iPhone から確認したい場合は `http://<PCのIPアドレス>:8000/` で開けますが、**http のため iOS では Service Worker が動かず、オフライン起動はできません**。オフライン動作の確認は https 配信後に行ってください。

## 7. 機能

| 画面 | 内容 |
|---|---|
| 記録 | 種目ごとのセット入力。重量の増減幅は種目ごとに設定でき（0.5〜10kg）、回数は 1 回刻み。種目を追加すると前回の重量が初期値に入る。前回の最高重量を超えると「自己ベスト」表示。同じ種目を同じ日に二重登録しようとすると警告が出て追加されない |
| 履歴 | 日付順の一覧。タップで展開し、その日を編集できる |
| 推移 | 種目ごとの最高重量の折れ線と、1回あたり総ボリュームの棒グラフ。推定1RM（Epley 式）も表示 |
| 設定 | JSON / CSV 書き出し、バックアップからの復元、テーマ切替、自分の種目の管理、全データ削除 |

### ジャンルでまとめて追加する

「腕の日」「脚の日」のようにメニュー構成を登録しておくと、「＋ 種目を追加」のシート最上部のジャンルをタップするだけで、その構成の種目がまとめて記録シートに入ります。すでに追加済みの種目は自動的に飛ばされ、「◯種目を追加（△件は追加済み）」と結果が出ます。

初回は「胸の日」「背中の日」「脚の日」「肩の日」「腕の日」の5つが入っています。設定画面の「ジャンル」から、名前の変更・削除・新規作成ができ、「編集」を押すと種目をタップで出し入れできます。一度削除したジャンルが勝手に復活することはありません。

### 重量の増減幅を種目ごとに変える

記録画面の各種目カードの右上、種目名の横にあるプルダウンで、＋− ボタン1回あたりの増減幅を選べます。0.5 / 1 / 1.25 / 2 / 2.5 / 5 / 10 kg から選択でき、種目ごとに保存されます（初期値は 2.5kg）。

ダンベル種目は 1kg、マシンは 5kg、バーベルは 2.5kg といった使い分けができます。設定画面の「種目」→「一覧」からもまとめて設定できます。回数の増減は 1 回で固定です。

### 種目を追加・削除する

**種目はすべて保存データ側で管理されます。** コードの中に種目リストは持っていません。初回起動時に 35 種目を「たね」として書き込むだけで、それ以降はすべて利用者のデータです。したがって最初から入っている種目も、自分で足した種目も、まったく同じように削除・カテゴリ変更ができ、アプリを更新しても削除したものが復活することはありません。

- **追加**：「＋ 種目を追加」のシート上部で、種目名を入力しカテゴリ（胸・背中・脚・肩・腕・体幹・その他）を選んで「追加」
- **削除**：シート右上の「編集」を押して種目名の横の ✕ をタップ。または設定画面の「種目」→「一覧」から削除
- **カテゴリ変更**：設定画面の「種目」→「一覧」で、各行のプルダウンから変更
- **初期状態に戻す**：設定画面の「種目」の「初期の種目を戻す」。不足しているものだけが足され、既存の種目やカテゴリ設定は変わりません

**削除しても過去の記録は残ります。** 一覧から選べなくなるだけで、履歴・グラフ・CSV にはそのまま出ます。すでに記録がある種目を消そうとすると確認が出ます。

設定画面の「すべての記録を削除」はトレーニング記録だけを消します。種目とジャンルの設定は残ります。

推定1RM は `重量 × (1 + 回数 ÷ 30)` による参考値です。実際に1回挙上できる重量を保証するものではありません。
