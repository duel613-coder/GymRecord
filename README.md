# ジムログ

日々のジムのトレーニングを記録する PWA。**データは端末の中だけに保存され、外部には一切送信されません。**

## ファイル構成

```
index.html               アプリ本体（HTML / CSS / JS すべて内包）
sw.js                    Service Worker（オフライン動作用）
manifest.webmanifest     PWA の定義
apple-touch-icon.png     iOS ホーム画面アイコン（180px）
icon-192.png             PWA アイコン
icon-512.png             PWA アイコン
icon-maskable-512.png    Android 等のマスク対応アイコン
favicon-32.png           ブラウザのタブアイコン
```

外部 CDN・Web フォント・解析スクリプトへの参照は一切ありません。初回アクセス後は完全にオフラインで動作します。

---

## 1. GitHub Pages に設置する

1. GitHub で新しいリポジトリを作る（例：`gymlog`）
   - 無料アカウントの場合、GitHub Pages を使うには **Public リポジトリ**にする必要があります
   - トレーニング記録はリポジトリに入らない（端末内にのみ保存される）ので、Public でも記録は公開されません
2. 上記ファイルをリポジトリの**ルート**にそのまま置いて push
3. リポジトリの **Settings → Pages** を開く
4. **Source** で `Deploy from a branch`、Branch は `main` / `/ (root)` を選んで Save
5. 1〜2 分待つと `https://<ユーザー名>.github.io/gymlog/` で公開される

> GitHub を使わない場合、Netlify Drop（https://app.netlify.com/drop）や Cloudflare Pages にフォルダをドラッグするだけでも同じことができます。いずれも https で配信されるため PWA として動作します。

---

## 2. iPhone のホーム画面に追加する

1. **Safari** で `https://<ユーザー名>.github.io/gymlog/` を開く（Chrome や他のアプリ内ブラウザでは不可）
2. 下部の共有ボタン（□に↑）をタップ
3. **「ホーム画面に追加」** を選ぶ
4. ホーム画面のアイコンから起動すると、アドレスバーのない全画面のアプリとして開く

一度この状態で開いておけば、以降は**圏外・機内モードでも起動します**（Service Worker がアプリ本体をキャッシュするため）。

---

## 3. アプリを更新する

1. `index.html` などを編集する
2. **`sw.js` の 1 行目付近にある `CACHE` の番号を必ず上げる**
   ```js
   const CACHE = "gymlog-v1";   →   const CACHE = "gymlog-v2";
   ```
   これを忘れると、端末に古いキャッシュが残って新しい版が反映されません
3. push する
4. iPhone でアプリを開くと「新しいバージョンがあります」と表示されるので「更新」をタップ

---

## 4. データについて

- 保存先は端末内の **localStorage と IndexedDB の両方**。片方が消えてももう片方から復旧します
- 外部サーバーへの送信は一切ありません
- ただし次の場合は消えます：
  - Safari の「履歴とWebサイトデータを消去」
  - ホーム画面からアプリを削除
  - iOS のストレージ逼迫時の自動削除
- **設定画面から定期的に JSON バックアップを書き出してください。** 最後のバックアップから 30 日経つと設定画面に警告が出ます
- 書き出した JSON は「バックアップから復元」で読み込めます。同じ日付は新しい方が残る形で統合されます
- CSV 書き出しは Excel / Numbers 用（日付・種目・セット・重量・回数・ボリューム・推定1RM・メモ）

## 5. Windows で動作確認する

`file://` で直接開くと Service Worker と一部の保存機能が動きません。簡易サーバー経由で確認してください。

```powershell
# このフォルダで
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます（localhost は例外的に Service Worker が動きます）。

同じ Wi-Fi の iPhone から確認したい場合は `http://<PCのIPアドレス>:8000/` で開けますが、**http のため iOS では Service Worker が動かず、オフライン起動はできません**。オフライン動作の確認は https 配信後に行ってください。

## 6. 機能

| 画面 | 内容 |
|---|---|
| 記録 | 種目ごとのセット入力。重量は 2.5kg 刻み、回数は 1 回刻みのボタンで調整。種目を追加すると前回の重量が初期値に入る。前回の最高重量を超えると「自己ベスト」表示 |
| 履歴 | 日付順の一覧。タップで展開し、その日を編集できる |
| 推移 | 種目ごとの最高重量の折れ線と、1回あたり総ボリュームの棒グラフ。推定1RM（Epley 式）も表示 |
| 設定 | JSON / CSV 書き出し、バックアップからの復元、テーマ切替、全データ削除 |

推定1RM は `重量 × (1 + 回数 ÷ 30)` による参考値です。実際に1回挙上できる重量を保証するものではありません。
